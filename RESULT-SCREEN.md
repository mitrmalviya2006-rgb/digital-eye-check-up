# Component 12 — Screening result screen

Component 12 consumes only the versioned Component 11 result. The screen has no inference path and does not read Component 9/10 values directly.

## Display gate

SPH/CYL/Axis are rendered only when all of these are true: C11 status is `VALID`, `valid` and `overallValid` are true, and `component12.status` is `READY_FOR_SCREENING_ESTIMATE` with `canPresentScreeningEstimate: true`. Both eye groups must be `VALID`, explicitly identified as right/OD and left/OS, each contain exactly one valid prediction with finite SPH/CYL and an available finite Axis (or explicitly not-applicable Axis), source IDs, and the expected units. Any mismatch becomes an error state with no values shown.

For `LOW_CONFIDENCE`, `INCONSISTENT`, `RETEST_REQUIRED`, and `INVALID`, values are withheld from the screen and `prescription-result-ready` handoff. C11 reason codes/messages are displayed as received. No values are substituted, rounded, averaged, or converted. Positive SPH/CYL values receive a leading `+`; Axis receives a degree symbol; the underlying numeric string precision is otherwise preserved.

## Events and downstream compatibility

- C11 `eye-validity-complete` mounts the screen.
- C12 `prescription-result-ready` carries a versioned, minimal result summary, timestamp, status, and reasons. It includes OD/OS measurement values only when the strict display gate passes. Future Components 14 and 15 can subscribe to this event, and should persist/export only after their own explicit user action.
- C12 `component13-retest-request` carries the source component, affected eyes, status, and C11 reason codes/messages, but no refractive measurements. Component 13 can subscribe to continue a retest flow.
- C12 `prescription-result-finished` signals the end action.

Components 13, 14, and 15 have not yet been implemented in this repository. The retest action emits the Component 13 handoff and honestly reports this limitation; this screen does not claim to perform a retest, save history, or create a PDF.

## Safety and privacy

The result is technical vision screening/refractive-error estimation, not diagnosis or a professional prescription. It does not replace a professional eye examination. The component performs no camera processing, network request, storage, or AI inference. Results remain in memory in the current tab. The visible session date/time is the timestamp generated by Component 11.
